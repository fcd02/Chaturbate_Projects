12. ACCURATE 640m MODEL INTEGRATION
Verified against NudeNet 3.4.2's official PyPI documentation:
- 320n is the package default/included model;
- 640m is a 640x640 YOLOv8m option;
- NudeDetector accepts model_path plus inference_resolution=640;
- the project publishes a 640m ONNX release weight.
v2.8 implements a one-time download to models/nudenet_640m.onnx and then instantiates
NudeDetector(model_path=..., inference_resolution=640).

LIMITATION: the actual 640m ONNX inference was not executed in this packaging container because the
NudeNet runtime/model is not installed/downloaded here. The detector contract and threshold logic were
exercised with deterministic detect_batch output. On the Windows PC, install_mobile_reviewer.bat verifies
NudeNet import; the first Accurate pass downloads the model and exercises the real ONNX runtime.

13. PRIORITY / DURABLE-JOB ARCHITECTURE REVIEW
Verified code paths:
- model tap sets interactive_demand before ready checking;
- clicked model preparation uses a dedicated single-worker interactive executor;
- offline selected-model preparation uses the same interactive executor;
- Non-NSFW monitor terminates/pauses its child when priority work is waiting;
- whole-library generator checks priority work between models/chunks;
- Keep Last and permanent deletion no longer hold heavy_io_lock for the whole job;
  they release between file operations and wait while phone-priority work is active.

14. WINDOWS STATE-WRITE HARDENING

PermissionError/WinError 5 locks instead of relying on one shared .tmp filename.
