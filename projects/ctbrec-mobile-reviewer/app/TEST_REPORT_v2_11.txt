- duplicate/reordered source-set protection;

- terminal failure after the configured maximum attempts (3);
- failed/retrying-only work does not freeze whole-library passes;
- batching/checkpointing of durable file jobs;
- current/requested model mosaic work preempts file batches between files;
- existing mosaics open immediately;
- ready chunks remain largest-to-smallest;
- clicked-model missing mosaics are promoted;
- next-ready/Next Model behavior;
- Recu remains enrichment only;
- authoritative mosaic sidecar source order remains unchanged.
