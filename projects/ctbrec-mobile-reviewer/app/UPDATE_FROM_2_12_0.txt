Updating CTBRec Mobile Reviewer v2.12.0 -> v2.13.0
=================================================

Recommended existing-install update
-----------------------------------
1. Stop Mobile Reviewer.
2. Extract CTBRec_Mobile_Reviewer_v2_13_0_PATCH.zip.
3. Overlay its CTBRec_Mobile_Reviewer folder onto the existing installation and
   allow replacement of program/source/static files.
4. Start Mobile Reviewer normally.
5. Fully close the iPhone Home Screen/PWA app and reopen it once. The shell cache
   namespace is ctbrec-shell-v2130.

The PATCH intentionally does NOT contain active user/runtime state such as:
- mobile_config.json / access PIN / secret key
- recording_roots.txt
- mobile_action_queue.json
- Recu session/browser profile
- catalog/ready/background state caches
- model metadata sidecars generated by your install
- logs or generated mosaics

Therefore the overlay cannot replace those files.

What to expect after first launch
---------------------------------
- Existing phone authentication should continue to work. Once authenticated, the
  PWA stores an installation-bound paired token that can heal future iOS cookie
  loss without asking for the PIN again.
- Model tabs should clear/switch immediately and then populate from cache/network;
  a slow old-tab response cannot overwrite a newer tab.
- Large model lists render progressively (120 initially) instead of thousands of
  DOM cards at once.
- Tapping a model validates at most the configured open-fast warm set (default 3)
  before returning; missing mosaics/index repair continue on the PC asynchronously.
- Original, Review, and Non-NSFW image extraction use bounded ffmpeg batches
  (default 6 frames/process) with per-frame fallback on missing outputs.

No mosaic regeneration is required merely because of this update. Existing valid
mosaics and sidecars remain compatible.
