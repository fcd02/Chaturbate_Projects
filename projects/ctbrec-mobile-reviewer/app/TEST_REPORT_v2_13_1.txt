Date: 2026-09-10

PURPOSE
-------
Emergency regression correction for the v2.13.0 real-phone symptom:
  PC temporarily unreachable — retrying automatically. Failed to fetch
followed by an empty model list.

IMPLEMENTED CORRECTIONS
-----------------------
- restored known-stable HTTP/1.0 server protocol
- removed Python-layer gzip from API JSON responses
- removed global Authorization: Bearer header from normal PWA requests
- retained paired-device cookie recovery through explicit POST /api/auth/recover
- decoupled bootstrap/status loading from catalog/model-list loading
- added bounded GET transport retries and automatic catalog reconnect
- preserves a same-tab last-good list during refresh failure
- still clears a genuinely different uncached tab so stale rows are never mislabeled
- PWA shell bumped to ctbrec-shell-v2131 / assets ?v=2131
- all v2.13 performance improvements remain
