CTBRec Discovery v0.4.6 — Release Validation Report
===================================================

Release purpose
---------------
Fix the repeated Git Bridge bootstrap failures at the release-engineering level. The v0.4.5 field log showed the current validator receiving {'seen': 3, 'imported': 3}, which exactly reproduces the old v0.4.0 Mobile Reviewer catalog importer. The clean v0.4.5 FULL SOURCE contained the repaired importer, but the v0.4.5 PATCH was a minimal diff and did not include discovery/importers.py. Therefore a machine that skipped/interrupted v0.4.1 could present newer version/validation files while still executing stale v0.4.0 runtime source.

Permanent release changes
-------------------------
- PATCH is now cumulative/self-healing, not a minimal diff.
- PATCH_MANIFEST.json requires patch_type=cumulative_public_source_overlay and min_supported_version=0.3.0.
- validation/source_manifest.json SHA-256 pins canonical source files.
- validation/runner.py verifies canonical hashes before behavioral validation.
- Git Bridge v1.2.0 rejects PATCH ZIPs missing a canonical file or containing a canonical hash mismatch.
- tools/release/build_release.py is the authoritative artifact builder.
- catalog/Recu cursor generations bumped to v46 / v46| for one corrective reparse.
